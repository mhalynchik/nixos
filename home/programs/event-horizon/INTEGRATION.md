# Event Horizon

Космический рабочий стол на Quickshell: ForestSmooth для заголовков, Sansation
для обычного текста, emerald, прозрачный календарь, орбитальный аудиоспектр.
Открытие меню — 1200 мс, закрытие — 700 мс, включая повторные открытия.

## Включение и обновление

`programs.eventHorizon = true` включён в `vars.nix.example` по умолчанию.
Существующий `/etc/nixos/vars.nix` получает этот параметр через merge defaults;
вручную переносить остальные персональные настройки не требуется.

Запустите `./bin/update`. На вопрос о vars можно выбрать «оставить».
После первого обновления выйдите из графического сеанса и войдите снова:
так завершатся старые экземпляры dock/applets, запущенные через exec-once,
и новые службы получат актуальное окружение Hyprland.

Модуль отключает перекрывающие AGS/SwayNC и автозапуск dock. Waybar сохраняет
логотип NixOS, рабочие столы, раскладку и трей; правую часть рисует Event Horizon.
Часы и календарь расположены на рабочем столе. SwayOSD и мультимедийные клавиши
остаются доступны. Обычная тема GTK/терминала по-прежнему определяется `theme`.

Служба `event-horizon.service` привязана к `hyprland-session.target`.
Её перезапуск завершает собственные адаптеры, но приложения из launcher
запускаются в отдельных systemd scopes и продолжают работать.

Горячие клавиши:

- Super+R — поиск приложений, файлов и действий.
- Super+N — уведомления; Super+Shift+N — очистить историю.
- Super+B — скрыть/показать обе части панели.
- Super+Shift+B — перезапустить панель и Event Horizon.
- В меню: Tab/Shift+Tab, Enter/Space, Escape, Alt+1…4.

Обои `event-horizon.png` устанавливаются в `staticWallpapersDir`. При первом
включении модуль выбирает их, сохранив предыдущий путь в
`~/.local/state/event-horizon/previous-wallpaper`. Последующие ребилды сохраняют
выбор пользователя. Штатные `wallpaper-picker`, `wallpaper-set` и анимированные
обои продолжают работать.

## Возможности и границы

- Настоящие MPRIS-плееры, управление треками, перемотка и CAVA-спектр.
- Звуковые устройства PipeWire/PulseAudio: громкость, mute, выбор выхода
  и микрофона, перенос потоков, громкость приложений.
- Сервер freedesktop Notifications, история 200 сообщений, действия живых
  уведомлений, группировка, прочитанное и «Не беспокоить».
- Launcher: приложения XDG, файлы стандартных домашних папок, фиксированные
  действия. Файловый индекс ограничен глубиной 3 и 10 000 файлами.
- Обзор Hyprland: карточки окон, переходы и перенос между столами.
- Локальные задачи/события и таймер с сохранением состояния. Внешней
  календарной синхронизации нет.
- Активный монитор, масштабирование, остановка постоянных анимаций закрытого
  меню и перекрытого рабочего стола; опция уменьшения движения.

Wi-Fi работает через D-Bus NetworkManager: список сетей, сигнал, сохранённые
подключения, пароль, включение и отключение. Bluetooth использует BlueZ:
поиск, сопряжение с подтверждением/PIN, подключение, отключение и забывание.
Пароли не передаются в аргументах процессов и не сохраняются оболочкой.
Для сложных профилей (например, нового 802.1X) остаются расширенные настройки.

Питание доступно справа в панели и через поиск. Сон, выход, перезагрузка
и выключение требуют подтверждения. Super+W открывает новый поиск.
Выбор изображений: Super+Shift+W; анимаций: Super+Alt+W. Наведение и клавиши
стрелок запускают предпросмотр; Enter сохраняет выбор, Esc восстанавливает
установленные обои. Предпросмотр не меняет обои экрана блокировки. После
остановки/сбоя оболочки служба восстанавливает установленный фон.

Emerald становится общей палитрой настроенных GTK/Qt-приложений, терминала,
браузера и Spotify при включённом Event Horizon. Sansation используется для
обычного интерфейсного текста; моноширинный шрифт редакторов сохраняется.
Приложения с собственными, неуправляемыми темами могут требовать настройки
внутри приложения. Прозрачность не меняется.

После перехода с прежнего запуска через `dbus-run-session` нужен новый вход
в систему: приложения, MPRIS и уведомления должны использовать общую шину
`/run/user/$UID/bus`. Ребилд сам по себе не переносит уже запущенные приложения
с прежней шины. Не запускайте отдельный SwayNC параллельно новой оболочке.

Тестовая музыка в обычном режиме не запускается. Пятиполосный эквалайзер
работает только с тестовым mpv; глобальный DSP не устанавливается.

Данные: `$XDG_STATE_HOME/event-horizon/desktop.json` либо
`~/.local/state/event-horizon/desktop.json`; атомарная запись, права 0600.
Повреждённые данные сохраняются как `.corrupt-*`. Для изолированных проверок
есть `EVENT_HORIZON_STATE_DIR`.

## Ручное управление и проверка

```sh
systemctl --user status event-horizon
journalctl --user -b -u event-horizon
event-horizon ipc call design open media
event-horizon ipc call design close
python3 -m unittest discover -s home/programs/event-horizon/tests
```

Разделы IPC: media, wifi, bluetooth, system, launcher, notifications, overview,
agenda, timer, power, wallpapers, animated. Повторный `open` текущего раздела закрывает его.
`event-horizon-preview` — отдельный режим с тестовым звуком;
не запускайте его одновременно с основной службой.

В пакете используется Quickshell из уже закреплённого nixpkgs-unstable;
`flake.lock` менять не требуется. В VM включите `programs.eventHorizon = true`
через [профиль проверки](../../../docs/ui-vm.md#профиль-для-новой-функции-или-темы).
Проверки интеграции: `UI_VM_STATE=… python3 tests/event_horizon_vm.py`.
Они сами ожидают новую службу; стандартные `bin/ui-vm wait/smoke` предназначены
для старого профиля AGS. Физические радио- и аудиоустройства проверяются на ПК.

[полученный файл](https://media.uprock.school/fonts/ForestSmooth/ForestSmooth-Regular.ttf).

## Возврат к прежнему интерфейсу

Установите `programs.eventHorizon = false;` в `/etc/nixos/vars.nix`, выполните
`./bin/update` с сохранением vars и перезайдите в сеанс. Вернутся прежние
Waybar, SwayNC и AGS (если `programs.ags = true`). Данные Event Horizon остаются.
Предыдущие обои можно выбрать через wallpaper-picker либо восстановить
командой `wallpaper-set "$(cat ~/.local/state/event-horizon/previous-wallpaper)"`,
если сохранённый файл существует.


Обновления управления:
- Галерея сохраняет выделение и клавиатурный фокус при загрузке миниатюр. Enter фиксирует выбор; последующее наведение не заменяет подтверждение. Esc отменяет неподтверждённый предпросмотр.
- Виджет плеера на рабочем столе: предыдущий трек, пауза/воспроизведение, стоп, следующий трек. В верхнем островке добавлена отдельная кнопка следующего трека.
- Wi-Fi показывает подтверждённое состояние NetworkManager. Поиск недоступен при выключенном или заблокированном адаптере; повторные запросы ограничены. Кнопка питания явно называет действие: «Включить» / «Выключить».
- Завершение таймера сопровождается однократным сигналом (3,2 секунды) на текущем выходе звука. Режим «Не беспокоить» скрывает всплывающие сообщения, но не сигнал установленного пользователем таймера. Системный mute и громкость не меняются.
